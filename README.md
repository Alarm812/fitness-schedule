# Fitness Schedule

## Опис проєкту

Fitness Schedule - це навчальний вебзастосунок для перегляду розкладу тренувань у фітнес-залі.

## Мета проєкту

Створити зручний спосіб перегляду актуального розкладу тренувань, щоб відвідувачі могли швидко знаходити потрібні заняття та планувати свої відвідування.

## Цільова аудиторія

Відвідувачі фітнес-залів, які регулярно відвідують тренування та потребують швидкого доступу до актуального розкладу.

## Основні функції

* Перегляд розкладу тренувань.
* Відображення назви, дати та часу тренування.
* Пошук і фільтрація тренувань.

## Статус проєкту

Навчальний проєкт. Етап ініціювання та планування.
