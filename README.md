# Fitness Schedule

## Опис проєкту

Fitness Schedule — це навчальний вебзастосунок для перегляду розкладу тренувань у фітнес-залі.

## Мета проєкту

Створити зручний спосіб перегляду розкладу тренувань, щоб відвідувачі могли швидко знаходити потрібні заняття та планувати свої відвідування.

## Основні функції

- Перегляд розкладу тренувань.
- Відображення назви, дати, часу та типу тренування.
- Пошук тренувань за назвою.
- Повідомлення про відсутність результатів пошуку.
- Адаптивне відображення на мобільних пристроях.

## Технології

- HTML
- CSS
- JavaScript
- Git та GitHub

## Запуск проєкту

1. Завантажити або клонувати репозиторій.
2. Відкрити папку проєкту.
3. Запустити файл `index.html` у веббраузері.

Додаткове встановлення залежностей не потрібне.

## Перевірка роботи

Перевірено такі сценарії:

- Відкриття сторінки та відображення розкладу.
- Пошук тренування за назвою.
- Відображення повідомлення, якщо результатів немає.
- Очищення поля пошуку та відновлення повного списку.
- Відображення сторінки на мобільному пристрої.

## Обмеження проєкту

- Дані тренувань зберігаються у вигляді тестового масиву в JavaScript.
- Підключення до бази даних або сервера відсутнє.
- Додавання, редагування та видалення тренувань не реалізовано.
- Авторизація користувачів відсутня.

## Статус проєкту

Реалізовано початкову версію MVP Fitness Schedule.
