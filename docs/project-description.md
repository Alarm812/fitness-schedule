# Опис проєкту

## Назва

Fitness Schedule

## Напрям

Вебзастосунок для перегляду розкладу тренувань у фітнес-залі.

## Проблема

Відвідувачам фітнес-залів не завжди зручно отримувати актуальну інформацію про розклад тренувань.

## Цільова група

Відвідувачі фітнес-залів, які регулярно відвідують тренування та потребують швидкого доступу до актуального розкладу.

## Мета

Розробити вебзастосунок, який дозволяє швидко переглядати актуальний розклад тренувань та знаходити потрібне заняття.

## MVP

* Перегляд розкладу тренувань.
* Відображення назви, дати та часу тренування.
* Відображення типу тренування.
* Пошук або фільтрація тренувань.
